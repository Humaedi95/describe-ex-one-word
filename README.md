One word. One verdict. **Obsolete.**

An ex who no longer runs, no longer updates, and no longer fits anywhere in
your life — not broken, not hated, just superseded. Like software nobody
installs anymore: it had its version, its time, and then the world moved on.

This entry is a small TypeScript program (`main.ts`, no dependencies) that
writes exactly that one word — `Obsolete`, 8 bytes, no trailing newline —
to `/output/entry.txt`.

## Run

```sh
node main.ts
```

`OUTPUT_DIR` can override the output directory for local testing; without it
the program writes to `/output`.
